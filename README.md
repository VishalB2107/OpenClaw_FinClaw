🦞 OpenClaw Financial Reasoning Layer for FinClaw

Overview

OpenClaw serves as the intelligent financial reasoning layer of the FinClaw ecosystem.

While the FinClaw Android application focuses on transaction detection and user awareness, OpenClaw acts as the financial intelligence engine that:

- Receives transaction events from FinClaw
- Categorizes financial activity
- Stores transactions in Actual Budget
- Generates spending insights
- Supports conversational financial queries through Telegram
- Processes receipt images and extracts transaction details

The project demonstrates how financial telemetry can be transformed into persistent conversational financial memory.

Core Features

📩 Transaction Event Processing

Receives structured financial events generated by FinClaw and processes them automatically.

Example:

{
  "eventType": "TRANSACTION_SYNC",
  "source": "android_sms",
  "transaction": {
    "amount": -299,
    "merchant": "Swiggy"
  }
}

---

🧠 Intelligent Categorization

Automatically categorizes transactions into meaningful financial groups such as:

- Food
- Entertainment
- Shopping
- Transport
- Utilities
- Other

---

💾 Persistent Financial Memory

Transactions are synchronized into Actual Budget, allowing long-term financial tracking and analysis.

---

🤖 Conversational Financial Assistant

Users can interact with their financial data naturally through Telegram.

Supported commands include:

/balance
/recent
/insights

Natural language queries:

show my last 5 transactions

how much did i spend this month

recent transactions

---

🧾 Receipt OCR Processing

Users can upload receipt images directly through Telegram.

The system extracts:

- Merchant Name
- Final Payable Amount
- Spending Category

and automatically creates a financial transaction.

Installation

Clone repository:

git clone https://github.com/KarthikMaiya/OpenClaw_FinClaw.git

Navigate to project:

cd OpenClaw_FinClaw

Install dependencies:

npm install

---

Environment Configuration

Create a ".env" file in the project root.

Example:

TELEGRAM_BOT_TOKEN=YOUR_BOT_TOKEN

ACTUAL_SERVER_URL=http://localhost:5006

ACTUAL_PASSWORD=YOUR_ACTUAL_PASSWORD

ACTUAL_SYNC_ID=YOUR_SYNC_ID

OPENCLAW_GROUP_ID=YOUR_GROUP_ID

---

Actual Budget Setup

Run Actual Budget server using Docker:

docker run -d \
  --name actual-budget \
  -p 5006:5006 \
  actualbudget/actual-server:latest

Open:

http://localhost:5006

Create a budget and configure credentials in the ".env" file.
